How it works. rea-games runs the original with its clock and random numbers controlled from outside, records the inputs, every random number and the state after each step, and checks a rebuild in any engine against that recording. The first difference is printed with its path.

Rebuild your own. Install the Claude Code plugin and ask: "rea this game: <link>, rebuild it in Godot."
